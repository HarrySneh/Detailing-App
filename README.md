# Iron & Amber – Toronto Mobile Auto Detailing

A high‑performance, responsive landing page for **Iron & Amber**, Toronto’s premier mobile detailing studio. Built with React, TypeScript, and Tailwind CSS, the site features a transparent pricing table, postal code checker, and a multi‑step booking modal that submits directly to Formspree.

---

## Features

- **Service Tiers & Pricing** – Dynamic table with three tiers (Amber Express, Iron Core, The Iron & Amber Reset) and per‑vehicle‑size pricing.
- **GTA‑Proof Add‑ons** – Winter salt extraction and pet hair removal with live price calculation.
- **Postal Code Checker** – Validates Toronto/GTA coverage using forward sortation area matching.
- **Multi‑step Booking Modal** – Guided flow (tier → vehicle size → add‑ons → contact → confirmation) with automatic total calculation and Formspree integration.
- **SEO‑ready** – Semantic HTML, meta tags, and fast Lighthouse scores.
- **Fully responsive** – Pixel‑perfect on mobile, tablet, and desktop.
- **Hash‑based routing** – Works flawlessly on GitHub Pages without server configuration.
